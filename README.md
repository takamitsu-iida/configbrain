# configbrain

Cisco公式マニュアルを根拠として、要求に沿った有用なコンフィグ案を生成するプロジェクトです。
全要求を満たす根拠が揃わない場合も、根拠のある部分設定、未充足項目、確認できた制約を提示します。
推論候補は根拠付きコンフィグと分離し、適用可能な設定として扱いません。

## 開発方針

新しい開発指示と合格条件は[instruction.md](./instruction.md)を参照してください。
最初は単一マニュアルと小さな評価例で、根拠の取得から部分設定の提示までを検証します。
文書の自動探索、全件変換、OKFパッケージ、ベクトル索引などは、必要性が確認されるまで追加しません。

## ローカル評価資料

`data/source_manuals/`には初期評価用のCisco Catalyst 9300 IOS XE 26.x IP設定マニュアルを
ローカル資料として置きます。PDFは著作権上の理由からGitへ追加しません。
